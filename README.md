# Portfolio Backend

NestJS + GraphQL + MongoDB. Sirve datos del portfolio de Lucas Santillan.

## Endpoints
- `POST /graphql` — GraphQL API
- Playground en dev: `/graphql`

## Variables de entorno
Ver `.env.example`.

## Seed admin user
```bash
SEED_USERNAME=lucas SEED_PASSWORD='xxxx' npm run seed
```

## Local
```bash
npm install
npm run start:dev
```
